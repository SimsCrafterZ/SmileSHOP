# What is it?<br>
-It's an unistore for installing SmileBASIC programs directly onto your 3DS.<br><br>
# how to install it?<br>

# How to use it?<br>
It's easy! Install the program you want and you will get a "program name" folder in sd/SmileSHOP/, example: sd/SmileSHOP/RAYCASTER<br>
Then move this folder into the "root" of SmileBASIC using sbfm (SmileBASIC file manager), available here: https://github.com/nnn1590/lpp-3ds-sbfm or on Universal Updater<br><br>
You can share your programs here: https://github.com/SimsCrafterZ/SmileSHOP/pulls
